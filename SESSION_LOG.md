# Session Log

Append-only record of every session that changed the dashboard. This is the
practical substitute for syncing raw chat transcripts — Claude's actual
conversation history lives only on the machine/account it ran on and cannot
be shared through git — so each session writes a short summary here instead.
This file is what makes `git pull` tell you "what changed and why", not just
"these lines of HTML changed".

**New entries go at the bottom**, in this format:

```
## YYYY-MM-DD HH:MM (who/whose session) — one-line title
**Code changed:** which files, and a one-line description of the change
**Chat summary:** 3-6 lines — what was asked, what was explored, what was
  rejected and why, anything a teammate would otherwise have to ask about
**Context updated:** what changed in CLAUDE.md, if anything
```

## 2026-08-19 (Anshul's session) — Adversarial audit and its fixes
**Code changed:** NSDC_Skill_Intelligence_Dashboard.html — retagged four instructor-derived KPIs measured→modelled; camera drawer header now states the KPI's own provenance and says "no camera on this space" for the Assessment Hall; kcard emits .is-modelled so the "Measured only" toggle works; provenance legend breakpoint 2080px→1180px; "ZONE · INVIGILATION AREA"→"ASSESSOR SUPERVISION AREA"; national metric register now defines assessment attendance against the eligible list; Active Class-Hours now compares against committed accreditation hours, not the declared daily schedule; offStats reports wall-clock minutes for both outage kinds (camera-minutes kept separately as camSlotMin) and no longer blames a server outage on one camera; PARTIAL/offStats/FEEDMETA on "All days" average the real days instead of unioning/summing
**Chat summary:** Ran a five-cluster adversarial audit of the executed dashboard, each finding then attacked by an independent skeptic — 30 confirmed, 19 refuted. Three All-days aggregates were dishonest (Feed Availability 24.0 h against a real 18.8 h mean; outage minutes collapsing to zero beside a card reporting 1,260 minutes without feed; gaps summed against averaged slots). One audit cluster died on a connection error and was not re-run — removed-KPI and two-source coverage came from the other clusters instead.
